# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest release | ✅ |
| older | ❌ |

Only the most recent release receives security fixes. Update to the latest
release before reporting.

## Reporting a vulnerability

If you believe you've found a security vulnerability in carrac-tui or the
Carrac API surface it talks to, please email **hello@carrac.cc** instead of
opening a public issue. We'll acknowledge as soon as we can and coordinate a
fix and disclosure with you.
